1) Breadcrumbs

Já falamos deles, mas resumindo:

Servem para mostrar o caminho da página atual.

Exemplo

Obras > Residência Souza > Orçamentos > Revisão 03

Quando usar
páginas internas
páginas de detalhe
telas com hierarquia
Benefício
reduz sensação de perda
melhora navegação
dá contexto imediato
2) Tabs

São abas dentro de uma mesma página ou contexto.

Exemplo em uma obra
Resumo
Orçamentos
Compras
Financeiro
Documentos
Diário
Agenda

Em vez de levar o usuário para páginas totalmente separadas, você pode concentrar tudo dentro do contexto da obra.

Quando usar
quando várias seções pertencem ao mesmo objeto
quando o usuário precisa alternar entre blocos relacionados
Benefício
navegação mais rápida
menos sensação de sair e entrar em telas
experiência mais fluida
Cuidado

Não colocar abas demais.
Se tiver muitas, fica ruim. Aí pode virar menu lateral interno.

4) Command palette / busca global

Esse é um recurso muito moderno.

É aquele painel que abre ao apertar algo como:
Ctrl + K

E permite pesquisar qualquer coisa:

obra
cliente
orçamento
fornecedor
item
documento
ação do sistema
Exemplo

O usuário digita:
“Souza”
e o sistema mostra:

Obra Residência Souza
Orçamento Residência Souza Rev. 2
Documento contrato Souza
Fornecedor Souza Materiais
Benefício
acelera demais o uso
passa sensação de sistema premium
reduz cliques
Excelente para você

Como seu SaaS tende a crescer em quantidade de módulos e registros, isso pode virar um grande diferencial.

5) Filtros salvos

Muito útil para sistemas com muita informação.

Exemplo em orçamentos

O usuário filtra:

status = pendente
obra = Residência Souza
categoria = elétrica

Depois ele salva isso como:
“Pendentes elétrica - Souza”

Exemplo em compras
entregas atrasadas
compras desta semana
pedidos aguardando cotação
Benefício
economiza tempo
melhora produtividade
faz o usuário sentir que o sistema “se adapta” a ele

Benefício
